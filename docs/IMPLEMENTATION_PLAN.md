# 分阶段实施计划

## Phase 0：基线与跨平台工程初始化
1. 在 Mac 安装并检查 Git、Node.js、npm、CodeBuddy IDE。
2. 创建 Electron + Vite + React + TypeScript 项目。
3. 检查 `package.json` 脚本，执行依赖安装、开发启动、测试和生产构建。
4. 在项目根目录配置 `CODEBUDDY.md` 与 `.codebuddy/` 规则/Skill。
5. 配置 `.gitignore`，保护 `.env`、原始照片、构建产物与个人配置。
6. 创建初始 Git commit，并在 Windows 电脑克隆同一仓库，验证安装依赖和基础测试。

验收：Mac 开发启动和构建成功；Windows 可克隆仓库并安装依赖；两端记录 Node/npm 版本与 commit SHA。

## Phase 1：透明桌宠窗口
1. 创建约 240×240 CSS px 透明无边框窗口。
2. 设计置顶、焦点和鼠标命中策略。
3. 实现安全的显示、隐藏、恢复、移动接口。
4. 使用占位符验证窗口行为。

验收：Mac 与 Windows 分别实测透明、无边框、置顶、点击、隐藏、恢复和退出；记录各平台差异。

## Phase 2：移动与状态机
1. 定义合法状态转换。
2. 实现 delta time 移动和目标停留。
3. 基于 screen workArea 限制边界。
4. 处理暂停、拖动、多显示器与负坐标。
5. 使用 Vitest 覆盖纯逻辑。

验收：单元测试通过；两端手动确认窗口不出界且拖动/暂停优先。

## Phase 3：PixiJS 与幺幺素材
1. 先接入单帧静态透明角色。
2. 对齐帧尺寸、锚点、脚底基线。
3. 实现 idle/walk/sit/lie 动画与朝向。
4. 验证资源在开发模式和打包后均能加载。

验收：两端角色显示正确、无明显裁切/抖动；缺失素材 fallback 正常。

## Phase 4：点击、拖动与菜单
1. 区分点击与拖动阈值。
2. 实现右键菜单与平台托盘/菜单栏入口。
3. 实现暂停/继续、显示/隐藏、退出。
4. 清理事件监听器、定时器与托盘资源。

验收：Mac 与 Windows 分别执行对应手动清单，不能以一端测试代替另一端。

## Phase 5：双端构建与发布验收
1. Mac 执行测试、类型检查、生产构建并验证 `.app`；需要时生成 DMG。
2. Windows 原生电脑执行相同自动化测试并生成 Windows 安装包。
3. 两端分别安装/启动/隐藏/恢复/退出/卸载。
4. 每端连续运行 30 分钟，观察 CPU、内存、动画和窗口行为。
5. 记录 commit SHA、OS 版本、CPU 架构、构建产物、测试结果和已知问题。

验收：双端 P0 项目全部通过；否则保留失败/待验证状态，不发布为通过版本。

## 开发节奏
一次只执行一个任务：检查现状 → 计划 → 最小修改 → 自动化验证 → 查看 diff → 平台实测/列待测 → 汇报。详细协作方法见 `docs/CROSS_PLATFORM_WORKFLOW.md`。
