# 双端测试与验收计划

## 1. 自动化测试（跨平台共用）

### PetStateMachine
- idle → walk、walk → idle。
- 暂停进入 paused；拖动进入 drag。
- drag 结束后恢复合理状态。
- 无效状态转换被拒绝或安全处理。
- 随机动作可通过注入随机源稳定复现。

### MovementController
- 正常移动与到达目标。
- 左、右、上、下边界约束。
- workArea 含负坐标。
- 暂停时位置不推进。
- 拖动时自动移动冻结。
- 显示器工作区变化后重新约束目标。

### Asset loader / Animator
- 资源成功加载。
- 资源缺失时 fallback。
- 空帧数组产生可读错误。
- 状态切换后旧 ticker/监听器被清理。
- 纹理复用与释放策略正确。

## 2. macOS 实机验收（Apple Silicon）
- [ ] 在开发模式启动并显示透明无边框窗口。
- [ ] 置顶策略符合预期，不无故抢占键盘焦点。
- [ ] 点击角色可响应；拖动不会被自动移动覆盖。
- [ ] 暂停/继续、隐藏/恢复、退出可用。
- [ ] 菜单栏/托盘入口行为正确（按实际实现）。
- [ ] Dock 图标、应用激活/退出行为符合设计。
- [ ] 多显示器、分辨率/缩放变化按支持范围验证。
- [ ] 休眠/唤醒后行为合理。
- [ ] `.app` 能启动，角色资源路径正确；若生成 DMG，完成安装/拖入应用程序文件夹测试。
- [ ] 关闭后进程与菜单栏图标正常清理。
- [ ] 连续运行 30 分钟，无明显卡死、崩溃或持续资源增长。

## 3. Windows 实机验收
- [ ] 在开发模式启动并显示透明无边框窗口。
- [ ] 置顶策略符合预期，不无故抢占焦点。
- [ ] 普通应用窗口可正常操作，桌宠不大面积拦截鼠标。
- [ ] 点击、拖动、右键菜单正确。
- [ ] 暂停/继续、隐藏/恢复、退出可用。
- [ ] 系统托盘菜单行为正确，关闭后无重复图标/残留进程。
- [ ] 改变分辨率、缩放比例。
- [ ] 多显示器按支持范围测试主副屏、负坐标与显示器断开。
- [ ] 休眠/唤醒后行为合理。
- [ ] Windows 安装包安装、启动、卸载；升级只在功能实现后验收。
- [ ] 安装后角色素材、图标与配置路径正确。
- [ ] 连续运行 30 分钟，无明显卡死、崩溃或持续资源增长。

## 4. 每次任务的验收记录
至少记录：
- 日期与测试人。
- Git commit SHA。
- OS 版本、CPU 架构、Node/npm 版本。
- 屏幕分辨率、缩放比例、显示器数量（窗口/显示相关任务）。
- 运行命令与自动化测试结果。
- macOS 实测：通过/失败/未验证 + 备注。
- Windows 实测：通过/失败/未验证 + 备注。
- 产物文件名/路径（若有）。
- 已知问题与复现步骤。

## 5. 交付报告模板

```text
任务 / commit SHA：
操作系统与架构：
执行命令：
自动化测试结果：
macOS 手动验收：通过 / 失败 / 未验证
Windows 手动验收：通过 / 失败 / 未验证
构建产物：
未验证项：
已知问题：
回滚方式：
```

不得把“代码已生成”写成“测试已通过”；不得把一个平台的结果复制为另一个平台的结果。
