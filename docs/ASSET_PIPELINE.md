# 幺幺角色素材流程

## 1. 素材目标

以用户提供的幺幺真实照片为参考，制作透明背景的角色图和基础动作帧。AI 生成的帧需要人工检查，不能假定生成结果天然一致。

## 2. 推荐素材目录

```text
src/renderer/src/assets/pet/
  idle/
  walk/
  sit/
  lie/
  metadata.json
```

如果构建工具对资源路径有特殊约定，先验证开发与打包后的读取方式，再决定最终目录。

## 3. 输入照片建议

- 清晰、对焦准确、光线均匀。
- 尽量完整展示头部、躯干和四肢。
- 行走参考图最好能看到侧面身体与脚部。
- 尽量避免毛发与背景颜色完全混合。
- 保留原始照片备份；处理过程只写入导出目录。

## 4. 处理步骤

1. 选取幺幺的原始参考照片。
2. 移除背景，导出带 alpha 通道的 PNG。
3. 检查白色毛发边缘、透明孔洞与阴影光晕。
4. 先完成单帧静态角色，验证桌面缩放和可见度。
5. 制作 walk 动作序列。
6. 再制作 idle、sit、lie。
7. 对齐所有帧的画布尺寸、脚底基线和视觉中心。
8. 记录帧率、帧顺序、动作循环属性。

## 5. metadata 示例

```json
{
  "idle": {
    "frames": ["idle/idle-01.png", "idle/idle-02.png"],
    "fps": 3,
    "loop": true
  },
  "walk": {
    "frames": [
      "walk/walk-01.png",
      "walk/walk-02.png",
      "walk/walk-03.png"
    ],
    "fps": 8,
    "loop": true
  }
}
```

示例仅说明数据结构，不代表这些文件已经存在。加载器必须验证文件存在性并在失败时使用占位符。

## 6. 素材质量检查

- 透明背景正确，不存在白色矩形底。
- 白色毛发边缘没有明显锯齿或灰边。
- 每帧脚底基线稳定。
- 角色尺寸不突然跳变。
- 左右转向时方向符合移动方向。
- 循环首尾没有明显跳帧。
- 动画帧率不会让角色显得过快或过慢。

## 7. 隐私

默认本地处理。任何使用第三方图像服务的步骤都应先由用户主动选择；不要自动上传照片。不要将原始照片提交到公开 Git 仓库。
