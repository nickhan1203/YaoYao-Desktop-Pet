# 产品需求文档（PRD）

## 1. 产品概述

产品名：幺幺桌面宠物（暂定）。
目标平台：macOS（Apple Silicon 优先）与 Windows 10/11（Windows 实机架构以实际设备为准，默认优先 x64）。
开发方式：macOS + CodeBuddy IDE 主开发，独立 Windows 电脑做兼容性实机验收；Electron + TypeScript。
核心体验：幺幺以真实照片加工的透明角色素材显示在桌面上，自主走动、停留、转向，并支持点击、拖动和暂停。

## 2. 产品目标
1. 稳定、低干扰、可随时隐藏的桌面宠物。
2. 尽可能保留幺幺这只纯白博美的辨识度。
3. 同一代码库支持 macOS 与 Windows，平台行为经过分别验收。
4. AI 辅助开发过程可分阶段验证、可回滚、可测试。
5. 为未来动作指令预留接口，但 MVP 不实现 AI 对话。

## 3. MVP 范围

### P0：必须完成
- Electron 透明、无边框桌宠窗口；置顶策略在两端分别验证。
- 显示、隐藏、恢复和正常退出。
- 在可用屏幕工作区内移动；到达目标后停留；靠近边界时合理转向。
- 点击与拖动；拖动期间禁止自动移动。
- 右键菜单和系统托盘/菜单栏入口提供暂停/继续、显示/隐藏、退出等基础操作。
- 缺少角色素材时显示占位符并输出可读错误。
- 状态机、移动边界、暂停、拖动有自动化测试。
- 在 macOS 构建和实测 `.app`；在 Windows 原生电脑构建并实测安装包。

### P1：尽量完成
- idle / walk / sit / lie 基础动作。
- 多显示器支持，包含负坐标与工作区边界。
- 本地设置角色大小、速度和自动移动开关。
- 两端各连续运行 30 分钟的初始稳定性测试。

## 4. MVP 明确不做
- LLM / AI 对话、语音、长期记忆、Agent 工具调用。
- 登录、云端同步、后端、数据库、遥测。
- 自动更新、应用商店发布、复杂设置中心。
- 3D 骨骼动画、复杂物理模拟、全屏透明覆盖层。
- 未经用户确认的开机自启动。

## 5. 验收指标
- 纯逻辑单元测试通过。
- macOS 开发模式与生产 `.app` 均可启动；Windows 开发模式与安装包均可启动。
- 两端图片、动画帧和图标路径正确。
- 两端分别通过透明、置顶、拖动、隐藏、恢复、托盘/菜单栏与退出测试。
- 自动移动不会在拖动或暂停时覆盖用户操作。
- 两端均完成至少 30 分钟稳定性测试（若作为正式 P0 交付门槛）。
- 验收报告记录 commit SHA、系统版本、架构和结果；未测试项明确标记为“未验证”。
- 任一平台 P0 失败或未验证时，不得宣称双端验收完成。

## 6. 低干扰与隐私
- 默认不播放声音、不抢占键盘焦点。
- 不创建全屏透明窗口，不监听无关键盘输入或采集屏幕内容。
- 用户可明确暂停、隐藏和退出。
- 原始照片默认本地保存，不提交到公开 Git，不自动上传第三方服务。
